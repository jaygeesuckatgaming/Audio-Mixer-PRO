# Audio Mixer PRO - Stream Deck plugin

Keys that mute strips of Audio Mixer PRO and light up with the console's real
state. Built and packaged here, installed with one double-click.

**End users install nothing else.** The Stream Deck app ships its own Node
runtime (7.1+) and the plugin has zero npm dependencies, so there is no Node
install, no `node_modules` and no Companion.

## What it does

| Action | Behaviour |
|---|---|
| **Strip Mute** | Mutes/unmutes one strip. Title shows the mixer's strip name; the key goes amber while the strip is muted, grey when live, `OFFLINE` when the mixer is closed. |
| **Mute All** | If any strip is muted, releases all of them; otherwise mutes every strip. |

Both react to changes made in the console as well: the plug-in re-reads the
mixer four times a second while at least one of its keys is visible, and not at
all when they are not.

## Requirements

- Audio Mixer PRO with **Stream Deck control** enabled (it is on by default;
  `MENU > Stream Deck Control (port 8765)` switches it, and the startup log
  records `control: listening on 127.0.0.1:8765`).
- Stream Deck **7.1** or newer (developed against 7.5.1).

## Install

Double-click `dist\com.jaygee.audiomixerpro.streamDeckPlugin` (built by
`package.ps1`). For development, `install-dev.ps1` copies the folder into the
Stream Deck plugins directory and `-Restart` restarts the app.

## How it talks to the mixer

```
Stream Deck app --WebSocket--> bin/plugin.js --HTTP 127.0.0.1:8765--> Audio Mixer PRO
```

- `GET /state` - strips (number, name, mute, solo, mono, gain), buses, toggles.
- `POST /command` - `{"cmd":"strip.mute","strip":2,"value":true}` or
  `{"cmd":"mute.all"}`.
- Every request carries the token from
  `%APPDATA%\Audio Mixer Pro\control.token`, which the plug-in reads itself.
  The API only listens on loopback, so it is not reachable from the network.

The port is fixed at 8765 on the plug-in side; if the console's port is ever
changed, the plug-in needs a setting for it (not implemented yet).

## Development

```powershell
# artwork (re)generated from tools/make-icons.ps1
powershell -ExecutionPolicy Bypass -File streamdeck\tools\make-icons.ps1

# syntax check
node --check streamdeck\com.jaygee.audiomixerpro.sdPlugin\bin\plugin.js

# end-to-end test without a deck: fake Stream Deck + the real mixer
node streamdeck\tools\fake-deck.js

# install into the deck app, then package for release
powershell -ExecutionPolicy Bypass -File streamdeck\install-dev.ps1 -Restart
powershell -ExecutionPolicy Bypass -File streamdeck\package.ps1
```

`tools\fake-deck.js` is a development harness: it serves the plug-in protocol on
a local WebSocket, launches `bin/plugin.js` against it, and checks that
registration, titles, lights and both mute commands reach the mixer. It needs a
running console with the control API enabled and the same `%APPDATA%` the
console wrote its token to (the test build was run with `--safe-mode` and a
temporary `APPDATA`).

Logs: the plug-in writes to `%APPDATA%\Elgato\StreamDeck\logs\plugins\` - open
the Stream Deck app's plugin log if a key does not light up.
